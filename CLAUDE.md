# ALCANZANDO SUEÑOS — Instrucciones del proyecto

Al empezar cada chat, leé `PROYECTO.md` para conocer el estado actual y continuá desde donde quedamos.

Al terminar cada chat, actualizá `PROYECTO.md` con todo lo que se hizo en la sesión.

Cuando el contador llegue a **[Msg 20/20]**, actualizá automáticamente `PROYECTO.md` antes de sugerir nuevo chat.

Este proyecto no pertenece a ningún cluster/HUB — es independiente de PresupuestoPRO y del resto de las carpetas de `D:\ESCRITORIO\CLAUDE`.
